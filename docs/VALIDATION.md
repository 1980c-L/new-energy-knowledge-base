# 验证结果与已知限制

日期：2026-11-14；L1 作品展示。对象为本仓库的本地运行与展示代码，不对政策现行效力或公网服务作验收。

## 本轮实际完成

- 修前版本由独立子 agent 阅读源码并进行受控内存模拟，发现材料遗漏、异步会话串号、DELETE 未转发、断流误报成功、动画帧覆盖卡片、桌面侧栏无法重新展开等 6 组问题。
- 对应前端问题已修复：保留限制性说明和证据索引，未识别内容完整回退；会话切换隔离旧响应；按完成事件区分成功、停止和中断；取消待绘制帧；补 DELETE 和侧栏展开。
- 修后浏览器回归 18/18，通过真实浏览器、真实前端及受控模拟 API 检查。追加复审发现的“历史尚未加载就续问”也已修复：加载期间禁发，Enter不能绕过，历史恢复后保持顺序和父消息。模拟结果不冒充真实服务运行。
- 本机真实 Dify—176 链路完成三条演示问题；历史三轮恢复、续问、重新查询通过；复制操作的写入目标采用受控模拟，检查复制内容保留原文和限制说明。
- 本轮独立访客的重命名、删除由真实同源 HTTP 接口执行并回读通过。完整浏览器脚本曾在菜单点击阶段超时，因此不把这两个操作写成该脚本完整通过。
- 桌面与 390px 手机端截图已留存；手机端横向溢出为 0px。截图只证明记录时的状态，不代表所有机型与全部可访问性要求通过。
- 运行前确认对话应用只有模板/HTTP/Answer 等节点，没有 LLM；已查询的对应 Dify workflow 运行记录 `total_tokens=0`。
- 最终独立发布前复核核对源码、导出依赖、配置清理与上述证据，历史加载续问补项关闭，本轮没有剩余源码展示发布阻塞。这个结论不替代未执行的公网运行验收。

## 导出包检查

本仓库从已存在的冻结运行副本与资料包导出，保留所需源码和版本身份。查询在新路径实际运行通过；5 项离线运行检查通过，覆盖安全例外保留、Wiki主张、官方未明确/无匹配区分、判定缺字段和关系追溯。源码并非仅供阅读的空壳。测试入口及最终结果以仓库 `tests/` 和发布提交为准。

发布前检查待提交文件、常见凭据形式、手机号形式与本地运行配置；未包含私有密钥、模型 Key、浏览器 Cookie、会话数据库或安装依赖目录。这是本轮发布内容检查，不是仓库级专业安全审计。

## 保留的限制

1. 网页是候选材料展示，首批只显示前四段，每段可能截断。页面明确标为原文节选，保留命中数及未展示提示；CLI 可查看完整返回材料。
2. 无关自然语言也可能匹配出政策材料；`materials_ready` 不等于答案正确或问题已在支持范围内。
3. “重新查询”会新增一轮，保留上一份结果；不承诺实现 Dify 的分支式重新生成。
4. “停止生成”终止当前浏览器请求；没有新增 Dify 服务端任务取消能力。无模型版本不产生由此继续推理的模型费用，但不把它推广为未来有模型版本的费用控制。
5. 界面当前只读取最近 30 条历史消息，没有完整历史翻页。
6. 本版未重新审查全部能源政策语义，未重新接受历史云模型回答，也没有增加任何云生成请求。
7. 公网部署与平台开通已按使用者要求取消；只发布 GitHub 源码和展示资料。
