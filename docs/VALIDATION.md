# 验证结果与保留的限制

日期：2026-11-14。验收对象是本仓库的**本地运行与展示代码**；政策现行效力和公网服务属另外的范围。

## 结论

本地运行通过，网页端检查全部通过；资料为冻结副本，结论按证据给出。逐项明细如下。

## 本轮验证内容

修前版本由独立子 agent 读源码并做受控内存模拟，查出 6 组问题：材料遗漏、异步会话串号、DELETE 未转发、断流误报成功、动画帧覆盖卡片、桌面侧栏无法重新展开。

对应修复已经落地：保留限制性说明和证据索引，未识别的内容完整回退；切换会话时隔离旧响应；按完成事件区分成功、停止和中断；取消待绘制的帧；补齐 DELETE 转发与侧栏展开。

**修后验证**：浏览器回归 18/18 通过，用的是真实浏览器、真实前端，接口层用受控模拟。追加复审又发现「历史还没加载完就续问」的问题，同样修掉了——加载期间禁止发送，回车也绕不过去，历史恢复后顺序和父消息保持正确。此处记录的是模拟接口的结果，与真实服务运行分开算。

**真实链路**：本机真实 Dify—176 链路跑通三条演示问题；历史三轮恢复、续问、重新查询均通过。复制操作的写入目标用受控模拟，检查的是复制内容是否保留原文和限制说明。

**独立访客操作**：重命名、删除由真实同源 HTTP 接口执行并回读通过。完整浏览器脚本曾在菜单点击阶段超时，因此这两项只记为「接口回读通过」，不算脚本整体通过。

**截图**：桌面端与 390px 手机端已留存，手机端横向溢出 0px。截图证明的是记录那一刻的状态，机型覆盖与全部可访问性要求另需检验。

**无模型确认**：运行前确认对话应用里只有模板、HTTP、Answer 等节点，没有 LLM；对应 Dify workflow 的运行记录 total_tokens=0。

**发布前复核**：源码、导出依赖、配置清理和上述证据逐项核对，历史加载续问这一补项已关闭，本轮没有剩余阻塞。此结论只覆盖源码展示发布，不替代尚未执行的公网运行验收。

## 导出包检查

本仓库从已有的冻结运行副本与资料包导出，保留所需源码和版本身份。查询在新路径下实际运行通过；5 项离线运行检查通过，覆盖安全例外保留、Wiki 主张、官方未明确与无匹配的区分、判定缺字段、关系追溯。源码可运行，不是仅供阅读的空壳。测试入口与最终结果以仓库 `tests/` 和发布提交为准。

发布前检查了待提交文件、常见凭据形式、手机号形式与本地运行配置：未包含私有密钥、模型 Key、浏览器 Cookie、会话数据库或依赖目录。这是本轮发布内容的检查，不等同于仓库级专业安全审计。

## 保留的限制

1. 网页是候选材料展示，首批只显示前四段，每段可能截断。页面标明了「原文节选」，并保留命中数量与未展示提示；完整返回材料用 CLI 看。
2. 与问题无关的自然语言也可能匹配到政策材料；`materials_ready` 不等于答案正确，也不等于问题在支持范围内。
3. 「重新查询」会新增一轮并保留上一份结果，与 Dify 的分支式重新生成不同，本版按前者实现。
4. 「停止生成」终止的是当前浏览器请求；本版不调用 Dify 服务端的任务取消能力。无模型版本本身不产生模型费用，未来接模型后的费用控制需另行设计。
5. 界面只读取最近 30 条历史消息，完整历史翻页尚未实现。
6. 本版未重新审查全部能源政策的语义，也未重新接受历史云模型回答，本轮没有新增云生成请求。
7. 公网部署与平台开通已按使用者要求取消，本轮只发布 GitHub 源码和展示资料。
